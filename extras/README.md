# Optional extras

Files under `extras/` are **not** part of Fever’s runtime. Fever never loads them automatically.

Copy what you need into your Fever web root (or follow the README in each subfolder).

| Folder | What it is |
|--------|------------|
| [`feed-api/`](feed-api/) | JSON/form API for lookup / refresh / update / delete (`api_key`) |
| [`feed-health/`](feed-health/) | Browser dashboard to live-check feeds and edit/delete broken ones (web login) |
